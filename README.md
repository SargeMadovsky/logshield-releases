# LogShield — сборки

Готовые архивы WordPress-плагина LogShield и файл `update.json`, по которому установленные плагины узнают о новой версии.

Файлы сюда кладёт GitHub Actions при выпуске версии. Руками ничего не меняйте.

- `update.json` — последняя версия, ссылка на архив, список изменений.
- `releases/logshield-<версия>.zip` — архивы всех версий.
